# Personal Profile Web Application

A web-based Personal Profile & Digital Resume Generator built using HTML, CSS, JavaScript, Java Servlets, and JavaServer Pages (JSP). This application collects user details through an interactive form, processes the data via an HTTP POST Servlet, and renders a modern, dark-themed personal profile dashboard complete with social links, skill metrics, profile editing, and a PDF resume export feature.

Frontend: HTML5, CSS3 (Custom Dark Theme UI & Responsive Layout), JavaScript

Backend: Java, Java Servlets (HTTP POST data handling), JavaServer Pages (JSP)

IDE: Apache NetBeans

Server / Web Container: ( GlassFish Server)

how to run and use Personal Profile web application in Apache NetBeans

Open the project in Apache NetBeans by going to File > Open Project... and selecting your web project folder.

Right-click the project, go to Properties, select the Run category, and choose your configured local server 

Right-click the project, select Clean and Build, then right-click again and select Run to launch your default web browser.

Fill in your personal details (Full Name, Student ID, Programme, Email, Hobbies, Bio, and profile picture) on the HTML form and submit it via HTTP POST.

View your generated dark-themed profile dashboard on the JSP page, and test the Modify Profile or Export PDF Resume buttons.
